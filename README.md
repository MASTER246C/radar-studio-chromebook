# Radar Studio Chromebook v0.1

Original browser prototype with top/front projections and serial radar display.
The project owner reported successful live radar operation on their Chromebook.
This is one user report, not broad hardware or firmware compatibility validation.

v0.1 can lose the visible vitals history on tracking-only frames. v0.2 adds
sparse-vitals retention, rotatable 3D view and track trails; it remains hardware-unverified.

Run from this extracted folder with `sh start-local.sh`, keep the Terminal open,
and open http://localhost:8000 in normal ChromeOS Chrome.
See QUICKSTART.md and TROUBLESHOOTING.md for full setup and limitations.
Vendor firmware/configurations and private inputs are deliberately omitted.
Supply your own exact known-working configuration for your installed firmware.
See PROVENANCE.txt for provenance and licensing status.
