# Radar Studio 0.9.0-preview.4

Continuous Original radar sessions use an exact-session firmware lease, with responsive manual Stop and bounded diagnostic retention. Timed tests remain available.

Users can select any browser-supported camera. Local folder recording preserves separate video segments, raw UART bytes and timing receipts. Camera-assisted review uses a pinned Apache-2.0 pose model, unvalidated activity proposals and explicit human decisions. Radar training import verifies original file hashes and matched-event timing while preserving measurement exclusions. No trained radar model or physical accuracy is claimed.

Camera and dataset work precede publication. C920e and firmware 0.3.2-rc1 physical acceptance are pending. Historical named releases retain their previous contents. See CAMERA_WORKFLOW.md for recording, privacy, review and training limits.
