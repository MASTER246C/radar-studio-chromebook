First verify status/ACK and no-RF port pairing; Start remains a separate manual action. Old one-port firmware cannot unlock this preview. A current successful onboard self-test and fault-free idle are required before Configure. Start requires a separate data-port nonce proof and fresh matching control status. Timed tests run for 1–5 seconds. Run until stopped requires the separately identified 0.3.2-rc1 continuous firmware and a healthy control heartbeat. Physical sensing, calibration and activity remain unvalidated.

Choose both interfaces on the same IWR6843AOPEVM: Enhanced is command/status at 115200 baud; Standard is measurement data at 921600 baud. Both are 8N1. The data port is read-only. Connection, configuration and port pairing never start RF.

A control-issued random nonce must be echoed on the data port and confirmed on control before Start. This detects mismatched ports and stale sessions; it is correlation, not authentication. If data is lost during a run, the viewer attempts Stop through control. Keep control connected. Timed tests have a firmware duration cap. In continuous mode, firmware stops if the matching control heartbeat is absent for five seconds. Keep this tab active and the PC awake.

Initial no-RF checkpoint: Query control status → enter and confirm mounting → Configure only → Verify port pairing · no RF → save capture JSON and both raw UART streams → stop for receipt review. Later separately authorized sensing: repeat fresh gates → separate manual Start in the configured mode. Pairing is unavailable until Configure succeeds.

Motion Signature Lab


Train your own sitting / walking / standing model from observed labels. The browser features and classifier are original; the current TI demo firmware still supplies points and tracks. This is a research prototype, not a safety or medical system.


No posture is treated as truth automatically. No real-world accuracy has been established. Use one consenting adult in an uncluttered test area. Capture and calibration guide


1 · Verify coordinates and repeatable mounting

Measure floor → flat top of the mounting bracket, just before the mounting screws. Add the signed vertical offset from that surface to the AOP antenna center (+ above, − below). These are measured values, not an exact guarantee. Your existing sensorPosition may already transform tracks; verify points and tracks separately. Unknown coordinates block collection.

4 · Record all available UART output

This independent recorder preserves every received UART byte and every decoded frame while active, including classifier-rejected observations. It is board-only serial output, not raw ADC. Arrival timestamps are the computer’s receipt time, not a synchronized sensor acquisition clock. Recording stops visibly at its memory limit; keep captures short and export each take.



No UART capture. Dataset licensing is pending; exports are private by default.




5 · Save your labeled features
Data stays in memory until you explicitly download it. Reloading loses unsaved work. Export includes derived feature windows, observed labels, calibration and session metadata; treat it as private. No server upload or automatic storage. Import replaces current data after confirmation; only import your own trusted capture files. Export is not a raw UART recording.
